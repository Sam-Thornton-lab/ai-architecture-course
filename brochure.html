Detailed Curriculum

10-Week Comprehensive Program with Assignments & Hands-On Exercises

Week 0: Orientation & AI Paradigm Shift

Foundation course introducing the mindset shift required for AI-augmented architecture. Explore how generative AI transforms the design process.

Learning Outcomes:

  • • Understand core concepts and terminology in AI/ML and generative models
  • • Develop mental models for AI-first architectural thinking
  • • Explore real-world case studies of AI-driven transformation

Assignment: Reflection Essay (500 words)

Document three architectural challenges where AI could provide value in your organization.

Week 1: Architectural Foundations & AI-Driven Documentation

Leverage AI for creating Architecture Decision Records (ADRs), capturing non-functional requirements, and documenting design trade-offs with precision.

Learning Outcomes:

  • • Master ADR templates and AI-powered documentation workflows
  • • Capture and prioritize non-functional requirements using AI assistance
  • • Create technology radar and strategic alignment documents

Hands-On Exercise: Create 3 ADRs

Using AI prompting, generate comprehensive ADRs for a real or hypothetical system migration.

Week 2: Domain-Driven Design & AI Event Storming

Apply DDD principles with AI-enhanced event storming sessions to identify bounded contexts, aggregates, and domain events at scale.

Learning Outcomes:

  • • Facilitate AI-assisted event storming workshops
  • • Identify and model bounded contexts in complex domains
  • • Design aggregate structures and establish domain language

Lab Exercise: Domain Model Design

Build event-driven architecture for a multi-bounded-context system.

Week 3: System Diagramming & Text-to-Diagram Automation

Guest Speaker Session • Generate system architecture diagrams, C4 models, and flow diagrams directly from AI-generated textual descriptions.

Learning Outcomes:

  • • Create C4 context, container, and component diagrams
  • • Use AI to generate diagram-as-code (Mermaid, PlantUML)
  • • Maintain diagram consistency and versioning

Assignment: Complete System Architecture

Generate full C4 model with AI assistance for a real business domain.

Week 4: Cloud Infrastructure & IaC Automation with AI

Design cloud-native architectures and auto-generate Infrastructure-as-Code configurations using AI prompting and best practices.

Learning Outcomes:

  • • Architect multi-region, highly-available cloud systems
  • • Generate Terraform/CloudFormation with AI assistance
  • • Optimize cost and performance in cloud design

Hands-On Lab: Infrastructure Design

Design and implement IaC for a production cloud environment.

Weeks 5–10

Week 5: API Architecture & Integration Design

Master REST, GraphQL, and gRPC design patterns enhanced with AI-generated specifications, OpenAPI documentation, and contract testing.

Learning Outcomes:

  • • Design API-first architectures and integration patterns
  • • Generate OpenAPI specifications and API documentation with AI
  • • Implement API versioning and backward compatibility strategies

Project Exercise: API Suite Design

Design a complete API strategy for a microservices ecosystem.

Week 6: Data Architecture & Vector Databases

Guest Speaker Session • Explore modern data patterns, vector databases, embeddings, and data pipeline architectures for AI workloads.

Learning Outcomes:

  • • Design scalable data warehouses and data lakes
  • • Implement vector search and semantic similarity patterns
  • • Optimize ETL/ELT pipelines for AI and analytics

Lab Assignment: Data Pipeline Design

Build end-to-end data architecture supporting ML/AI inference.

Week 7: Security, Zero-Trust & AI Threat Modeling

Apply zero-trust architecture principles and use AI to perform threat modeling, risk assessment, and security hardening at scale.

Learning Outcomes:

  • • Design zero-trust security architectures
  • • Conduct AI-assisted threat modeling and risk analysis
  • • Implement identity, encryption, and compliance patterns

Assignment: Threat Model & Mitigation Plan

Create comprehensive threat model with AI-generated risk assessment.

Week 8: Code-Level Architecture & SOLID Principles

Translate architectural vision into clean, maintainable code using SOLID principles, design patterns, and AI-assisted code review practices.

Learning Outcomes:

  • • Apply SOLID principles in real codebases
  • • Implement tactical design patterns with AI guidance
  • • Use AI for code review and architectural compliance

Hands-On Exercise: Code Refactoring

Refactor legacy code using AI-assisted analysis and SOLID principles.

Week 9: GenAI Architecture & Production RAG Systems

Guest Speaker Session • Design production-grade Retrieval-Augmented Generation (RAG) systems, LLM integration patterns, and AI pipeline architectures.

Learning Outcomes:

  • • Design RAG architectures for knowledge-intensive applications
  • • Integrate LLMs into production systems safely and efficiently
  • • Implement monitoring, caching, and optimization strategies

Project: RAG System Architecture

Design complete RAG pipeline for enterprise knowledge management.

Week 10: Capstone Defense & System Architecture Review

Present comprehensive architecture projects, defend design decisions, receive expert feedback, and earn certification of completion.

Capstone Requirements:

  • • Complete system architecture document (10–15 pages)
  • • Live presentation (20 minutes) + Q&A session (10 minutes)
  • • Peer and instructor feedback session
  • • Architecture portfolio submission for future reference

Each week includes supplementary materials, recorded sessions, and office hours with the instructor.
